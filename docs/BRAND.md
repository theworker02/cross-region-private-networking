# Brand

**Product:** Cross-Region Private Networking (fabric)  
**Mark:** Geometric “lattice bridge” — two nodes linked by an authenticated arc.  
**Independent project; not affiliated with Render.**

## Assets

| File | Use |
|------|-----|
| `assets/brand/logo.svg` | Primary logo |
| `assets/brand/icon.svg` | App icon / mark |
| `assets/brand/favicon.svg` | Favicon |
| `site/` embeds SVG directly | Pages |

PNG rasterization may be produced by operators from SVG; SVG is the source of truth in-repo.

## Color

- Ink: `#0B1F2A`
- Accent: `#1F7A6B` (teal — not Render purple)
- Light ground: `#F4F7F6`
- Dark ground: `#0B1F2A`

## Do / Don't

- Do: state independence from Render clearly on marketing surfaces  
- Don't: imitate Render wordmark, purple gradient, or claim partnership
