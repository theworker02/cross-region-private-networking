About this project

Cross-Region Private Networking (working title: Fabric) is a Rust identity-aware service fabric designed to extend same-region private networking into a global, named, policy-controlled mesh — with acquisition diligence materials for qualified buyers.

What ships in 1.0.0

  • fabric-core + fabric-cli (identity, DNS, rustls mTLS, policy, quarantine)
  • Honest SIMULATED multi-region drills and evaluation harness
  • Full acquisition/ diligence package
  • This presentation site (GitHub Pages)
