About this project

Cross-Region Private Networking (Fabric) is a Rust identity-aware service fabric designed to extend same-region private networking into a global, named, policy-controlled mesh — packaged for serious acquisition diligence.

What ships

  • v1.0.0 — frozen implementation: fabric-core + fabric-cli, rustls mTLS, evaluate harness
  • v1.1.0 — expanded data room: product brief, ICP, competitive landscape, insertion points, evaluation guide, legal draft checklists
  • This GitHub Pages presentation (SIMULATION demo, target narrative, contact)
