About this project

Cross-Region Private Networking (Fabric) is a Rust identity-aware service fabric designed to extend same-region private networking into a global, named, policy-controlled mesh — packaged for acquisition diligence.

What ships in 1.0.0

  • fabric-core + fabric-cli — identity, DNS, rustls mTLS, policy, quarantine
  • SIMULATED multi-region drills and evaluation harness
  • Full acquisition/ diligence tree
  • This GitHub Pages presentation
