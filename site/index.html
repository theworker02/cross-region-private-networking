Extend Render private networking globally

Render already provides excellent same-region private networks. Fabric adds cross-region names, rustls mTLS identity, and policy — preferring LOCAL_NATIVE in-region and authenticated fabric paths only when crossing regions.

Live demo (SIMULATION) Acquisition package Contact

Problem

Private networking on Render is region-scoped. Virginia cannot privately address Frankfurt over Render’s internal network alone — teams often fall back to public + app auth.

Path classes

  • LOCAL_NATIVE — same region → Render private hostname
  • FABRIC_DIRECT — cross-region authenticated path
  • FABRIC_RELAYED — via public fabric ingress (not Render private net)
