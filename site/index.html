Extend Render private networking globally

Render already provides excellent same-region private networks. This fabric adds cross-region names, rustls mTLS identity, and policy — preferring native private hostnames in-region, and authenticated fabric paths only when crossing regions.

Live demo (SIMULATION) Acquisition package Contact

The problem

Private networking on Render is region-scoped. A service in Virginia cannot privately address a peer in Frankfurt over Render’s internal network alone. Teams often fall back to public networking plus application auth.

Path classes

  • LOCAL_NATIVE — same region → Render private hostname
  • FABRIC_DIRECT — cross-region authenticated path
  • FABRIC_RELAYED — via fabric ingress (not Render private net)
