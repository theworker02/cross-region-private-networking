# Code of Conduct

## Our standard

We expect professional, respectful interaction in any channel related to this project (email, issue trackers if enabled, diligence calls, and security reports).

## Expected behavior

- Be respectful and concise.  
- Assume good faith in technical disagreement.  
- Keep confidential and acquisition materials out of public channels (`TRADE_SECRETS.md`).  
- Report security issues privately (`SECURITY.md`).  

## Unacceptable behavior

- Harassment, discrimination, or personal attacks  
- Publishing others’ private information  
- Spam, social-engineering attempts, or malicious content  
- Using project channels to solicit unauthorized access to systems  
- Dumping confidential diligence materials into public issues  

## Scope

This Code applies to project spaces controlled by the Rightsholder and to publicly representing the project when acting on the Rightsholder’s behalf.

## Enforcement

Violations may result in warnings, bans from communication channels, rejection of Submissions, or referral to appropriate authorities for illegal activity. Contact `[CONTACT_EMAIL]` to report conduct concerns.
